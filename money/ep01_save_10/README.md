## Шаг 1. Озвучка в Fish Audio (≈ 30–40 минут)
1. Откройте Fish Audio → Text to Speech.
2. Выберите голос: тёплый, уверенный, американский (English, US). Прослушайте 3–4 голоса на блоке 01 и оставьте один —
   он будет голосом канала навсегда.
3. Скорость 1.0. Вставьте блок **01** из `fish_audio.md` целиком → Generate → прослушайте → Download.
4. Переименуйте файл в `01.mp3`. Так же блоки 02 … 24 → `02.mp3` … `24.mp3`.
5. Если в блоке ошибка (не так ударение, проглотил слово) — просто сгенерируйте этот блок ещё раз.

**Совет:** числа в тексте уже написаны словами («thirty-six thousand five hundred»), чтобы голос не ошибался.

## Шаг 2. Отправить мне файлы
Пришлите 24 файла в чат (если не прикрепляются — загрузите в репозиторий через GitHub: Add file → Upload files,
папка `money/ep01_save_10/audio/`, и напишите мне).

## Шаг 3. Я собираю финальный ролик
Я запускаю две команды — сцены сами подстраиваются под длину каждого блока озвучки, голос вклеивается в видео:
```bash
cd money/ep01_save_10 && python3 build.py --audio audio
cd ../../anim && NODE_PATH=$(npm root -g) node render.js scenes/money01.js out/money01_final.mp4 --data ../money/ep01_save_10/scenes.json --audio ../money/ep01_save_10/voice.wav
```
Потом добавлю тихую фоновую музыку и пришлю вам готовый mp4.

## Шаг 4. Загрузка на YouTube
Всё для заполнения — в `upload.md`. Главное:
- аудитория: «Нет, это видео не для детей»;
- «Изменённый или синтетический контент»: для рисованной анимации обычно «Нет»;
- обложку загрузить свою (`thumbnail.png`);
- время публикации: вечер по США (например, 18:00–20:00 по Нью-Йорку = 01:00–03:00 по Москве) — можно поставить по расписанию.
