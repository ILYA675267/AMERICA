# Библиотека поз Майло (от пользователя, ChatGPT, 06.11.2026)

Исходники: `src/` (листы с белым фоном). Готовые позы на прозрачном фоне: `png/milo_<имя>.png`.
Вырезать новый лист 2×2: `python3 -I pilots/poses/cut_sheet_2x2.py <лист> pilots/poses/png <имя1> <имя2> <имя3> <имя4>`. Обзор на тёмном фоне: `milo_poses_sheet.png`.

| Поза | Когда использовать |
|---|---|
| confident | уверенно стоит, руки на поясе, «!» |
| excited_wave | радость, приветствие, «ура» |
| idea | идея, лампочка |
| laptop | работает/учится за ноутбуком |
| laugh_laptop | смеётся у ноутбука, успех |
| phone | смотрит в телефон, уведомление |
| presenting | объясняет по графику (рост, статистика) |
| question_think | задумался, «?» |
| reading | читает книгу (про мозг) |
| shrug | не знает, «??» |
| sit_think | сидит и думает |
| talking | говорит, облачко «...» |
| tired_sigh | устал, вздох, голова кружится |
| walking | идёт (вид сбоку, линии скорости) |
| angry | злится, руки в боки, значок гнева |
| frustrated_steam | бесится, пар из ушей |
| sad_hug_knees | грусть/депрессия, сидит обняв колени |
| facepalm_stress | стресс, лицо в ладони, каракули над головой |
| laptop_brain | ноутбук с мозгом (исследует психологию) |
| magnifier | исследует, лупа |
| thinking_idea | думает, облачко с лампочкой |
| meditating | медитирует, спокойствие |
| surprised | удивлён/шокирован, «!» |
| furious_stomp | в ярости топает ногами |
| crying | плачет, лужица слёз |
| victory | победа, кулак вверх, искры |
| thinking_gears | размышляет, облачко с шестерёнками (как работает мозг) |
| reading_happy | с радостью читает книгу |
| realization | озарение/«ой!», руки у лица, «!» |
| sleeping | спит на камне, «zzz» (сон, отдых, лень) |

Правило: Майло не анимируется кодом — только смена поз + лёгкий эффект речи (покачивание, «дыхание»,
подпрыгивание на фразе, субтитры). Не хватает поз/локаций — попросить пользователя.
